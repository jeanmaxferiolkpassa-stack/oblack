ICÔNES O'BLACK — À CRÉER

Ce dossier doit contenir 2 images PNG :

1. icon-192.png  →  192 x 192 pixels
2. icon-512.png  →  512 x 512 pixels

DESIGN
------
Fond : noir (#000000)
Texte : "O'BLACK" en jaune (#FACC15), centré
Police : Montserrat Bold ou Anton

COMMENT LES CRÉER (Canva, gratuit)
----------------------------------
1. canva.com → design 512 x 512 px
2. Fond noir, texte "O'BLACK" jaune, centré
3. Télécharger en PNG → renommer icon-512.png
4. Redimensionner à 192 x 192 → icon-192.png
5. Placer les 2 fichiers dans ce dossier

Sans ces icônes, l'app fonctionne quand même
(icône par défaut de Next.js sur l'écran d'accueil).
